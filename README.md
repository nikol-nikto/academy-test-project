# Coffee Time — сайт кофейни

## О проекте
Учебный групповой проект по дисциплине «Информационные технологии».

Цель проекта — разработать многостраничный сайт кофейни с использованием HTML и CSS.

## Страницы сайта
- **Главная** (`index.html`) — информация о кофейне.
- **Меню** (`menu.html`) — список напитков и десертов.
- **О нас** (`about.html`) — история и описание кофейни.

## Используемые технологии
- HTML5
- CSS3
- Git
- GitHub
